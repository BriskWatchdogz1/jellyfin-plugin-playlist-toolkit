# Security

Please report vulnerabilities privately, not in a public issue: use **Report a vulnerability** on the
Security tab of <https://github.com/BriskWatchdogz1/jellyfin-plugin-playlist-toolkit> (GitHub Private
Vulnerability Reporting).

A useful report says which plugin and Jellyfin version you run, what you did, what you expected, what
happened instead, and how an attacker would use it. Do not include real access tokens, passwords or
server addresses.

Only the latest release is supported.
